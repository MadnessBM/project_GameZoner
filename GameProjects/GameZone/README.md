Инструкция по установке и запуску GameZone после получения ZIP-архива
1. Распаковка проекта
1. Получить архив GameZone_Project.zip.
2. Нажать на него правой кнопкой мыши.
3. Выбрать «Извлечь всё».
4. Распаковать проект, например, в папку:
C:\Projects\GameZone


2. Установка необходимых программ
Перед запуском необходимо установить:
- XAMPP;
- Composer;
- PHP (можно использовать PHP из XAMPP);
- Visual Studio Code (необязательно).
3. Запуск XAMPP
1. Открыть XAMPP Control Panel.
2. Запустить Apache.
3. Запустить MySQL.
4. Создание базы данных
1. Открыть браузер.
2. Перейти по адресу:
http://localhost/phpmyadmin


3. Создать новую базу данных с названием:
gamezone


4. Выбрать кодировку utf8mb4_unicode_ci.
5. Открыть вкладку «Импорт».
6. Выбрать файл gamezone.sql.
7. Нажать кнопку «Импорт».
После этого таблицы и данные проекта появятся в базе данных.
5. Настройка проекта
1. Открыть папку GameZone в Visual Studio Code.
2. Найти файл .env.example.
3. Создать на его основе файл .env.
4. Указать настройки подключения к базе данных:
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=gamezone
DB_USERNAME=root
DB_PASSWORD=


5. Убедиться, что в .env указан действительный APP_KEY. Если ключ отсутствует, его можно создать командой php artisan key:generate.
6. Установка зависимостей
Открыть терминал в папке проекта и выполнить:
composer install


После установки зависимостей выполнить:
php artisan config:clear


Если проект использует стандартную публичную файловую систему Laravel, дополнительно выполнить:
php artisan storage:link


7. Запуск сайта
В терминале выполнить:
php artisan serve


После запуска открыть браузер и перейти по адресу:
http://127.0.0.1:8000


Проект запущен
8. Вход в административную панель
Для перехода к странице авторизации открыть:
http://127.0.0.1:8000/admin/login


Ввести электронную почту и пароль администратора, переданные отдельно автором проекта.

После успешной авторизации откроется административная панель:
http://127.0.0.1:8000/admin/games


В ней доступны функции добавления, редактирования и удаления компьютерных игр.
9. Завершение работы
Чтобы остановить сайт, необходимо:
1. Вернуться в терминал.
2. Нажать Ctrl + C.
3. При необходимости остановить Apache и MySQL в XAMPP.
